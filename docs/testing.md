# Security Testing and Validation

Secure Microservices Inventory System. Test run of 2026-10-23.

## Scope and method

| Item | Detail |
|---|---|
| Target | Gateway and three services run locally; SQL Server, RabbitMQ, Redis in Docker |
| Attack cases | `tests/AttackTests.cs`: 36 scripted cases, each tied to a threat ID in `threat-model.md` |
| SAST | Semgrep (p/csharp, p/secrets, p/owasp-top-ten), all 7 repositories |
| Secret scan | Gitleaks, full git history of all 7 repositories |
| DAST | OWASP ZAP active API scan of all 19 gateway routes, authenticated |

## Static analysis (Semgrep)

244 files scanned, 95 rules, 5 findings.

| Finding | Location | Assessment |
|---|---|---|
| GitHub Action referenced by mutable tag (x4) | AuthLibrary, ResponseLibrary `publish.yml` | Valid, low (supply chain). Fix: pin to commit SHA |
| `ValidateLifetime = false` | IdentityService `TokenService.cs` | By design: refresh must accept an expired token; signature and refresh token are still checked (A9) |

10 files were only partly parsed (newer C# syntax), so some code may be unchecked.

## Dynamic analysis (OWASP ZAP)

The gateway's OpenAPI description is generated by `tests/zap/build_openapi.py`. All requests were authenticated; an earlier run without the token was discarded. The scan was repeated after fixing the first run's findings.

| Alert | Run 1 | Run 2 (after fixes) | Assessment |
|---|---|---|---|
| High | 0 | 0 | 117 to 118 rules passed, incl. SQL injection, XSS, path traversal, server errors |
| Source Code Disclosure - SQL (Medium) | 0 | 1 | False positive: the product list now returns V2's stored test string "DROP TABLE Products" |
| X-Content-Type-Options missing (Low) | 3 | 0 | Fixed: `nosniff` at the gateway |
| Cross-Origin-Resource-Policy missing (Low) | 3 | 0 | Fixed: `same-origin` at the gateway |
| Unexpected Content-Type on `/` (Low) | 2 | 0 | Fixed: static HTML page removed |
| Strict-Transport-Security missing (Low) | 5 | 5 | Expected: scan ran in Development; HSTS is on outside Development |
| Cache-Control directives (Info) | 3 | 3 | `no-store` set; ZAP suggests also `no-cache, must-revalidate` (redundant with no-store) |

## Issues found during testing

| Issue | Found by | Status |
|---|---|---|
| Forged tokens crashed the request instead of returning 401: ASP.NET placed authentication before the header-stripping middleware | A2 to A6 | Fixed (explicit middleware order), retested 30/30 |
| Product list cached for 60 minutes and never invalidated on create, update or delete | V2 | Fixed (cache key removed on every write), V2b passes |
| A bad Authorization header writes a 401 body even on anonymous routes (login, refresh) | Code review during testing | Open |
| Missing security headers and static page | ZAP | Fixed, ZAP run 2 and I3/I4 pass |
| Mutable CI action tags | Semgrep | Open |
| Inventory could not reach Product through the gateway (dev certificate not trusted), so `items/{id}` returned 500 | End-to-end check | Fixed: gateway serves a project CA certificate that Inventory validates |
| That 500 carried the service's stack trace and the caller's JWT through the gateway | Same check | Fixed: gateway replaces downstream 5xx bodies; retested with SQL stopped, 33/33 still pass |
| Restore with an empty package cache resolved AuthLibrary 2.0.0 from an unrelated nuget.org author (dependency confusion) | Clean-machine restore | Fixed: packages bundled in `nuget-local`, source mapping; missing folder now fails restore |

## Limitations

- One machine, local development certificates.
- Some tokens are minted with the real private key to test expiry and algorithms; an attacker would not hold it.
- A13, A14 and V1 call Identity directly with the gateway certificate, to stay under the rate limit.
- No load testing.

## Reproducing

With the stack and all four services running: `dotnet run tests/AttackTests.cs` (from MCSC6002_System). For ZAP: `python tests/zap/build_openapi.py https://host.docker.internal:7000`, then the ZAP API scan with `ZAP_AUTH_HEADER=Authorization` and `ZAP_AUTH_HEADER_VALUE="Bearer <token.txt>"`.
